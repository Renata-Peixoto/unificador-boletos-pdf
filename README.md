# Unificador e Conciliador Automático de Boletos (PDF)

Aplicação desktop em **Python** (`Tkinter` + `pypdf`) para conferir relatórios contra lotes de boletos em PDF, validando simultaneamente os valores antes de unificar os documentos.

## Como executar
```bash
pip install -r requirements.txt
python juntar_boletos_arruda.py
```
